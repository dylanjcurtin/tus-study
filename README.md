# Study website

Participant-facing website for the TUS mood and decision-making study (ethics ref 6295).

## Editing

Each tab is one `.qmd` file (plain Markdown).

- `index.qmd` – About the study
- `before-your-visit.qmd` – planning your visit
- `finding-us.qmd` – directions
- `contact.qmd` – how to get in touch

Photos go in `images/`. The approved information sheet is in `assets/`.

## Preview locally

    quarto preview

## Publish

    quarto publish gh-pages

The site is at https://dylanjcurtin.github.io/tus-study
